SENSE+ v0.2 | 휴대폰 앱과 PC 관제 빠른 시작
=========================================

[PC에서 실행]
1. Python 3.11 또는 3.12를 준비합니다.
2. 저장소의 apps/sense-plus 폴더에서 Windows는 setup_windows.bat,
   Mac은 setup_mac.command를 한 번 실행합니다. 기존에 설치한 이 앱의 가상환경은 재사용할 수 있습니다.
3. Windows는 start_windows.bat, Mac은 start_mac.command를 실행합니다.
   PC 관제는 http://127.0.0.1:8766, PC 사용자 앱은 http://127.0.0.1:8765입니다.
4. 종료하려면 서버를 실행한 터미널에서 Ctrl+C를 누릅니다.

[휴대폰 연결]
1. PC 모드 서버를 종료하고 start_phone_windows.bat 또는 start_phone_mac.command를 실행합니다.
2. 같은 Wi-Fi에 연결한 PC의 Wi-Fi IPv4 주소를 입력합니다.
3. 스크립트가 표시하는 SENSE-test-root.cer 공개 인증서를 테스트 휴대폰에 전달합니다.
   개발 CA를 테스트 기기에서 신뢰하는 절차는 README_KO.md에 있습니다.
4. 휴대폰 카메라 앱으로 PC 관제의 QR을 스캔해 Safari 또는 Chrome에서 엽니다.
   카메라·마이크 권한을 허용합니다. 서버를 다시 시작했으면 새 QR을 스캔합니다.
5. 주변 확인을 한 번 누르면 장면이 달라질 때마다 자동 분석합니다.
   음성 질문을 누르고 말한 뒤 말하기 완료를 누릅니다. 연결을 끝내려면 안내 종료를 누릅니다.
6. 관제에서 세션을 선택해 실제 수신 FPS와 질문 음성 레벨을 확인합니다.
   영상은 자동 미리보기를 켰을 때 표시됩니다. AI가 선택한 프레임 번호는 세션 상세에 표시됩니다.

[모델과 검증]
- 기본 설정은 통신 시험입니다. 로컬 Qwen3-VL, Whisper, Heami를 켜려면 docs/INTEGRATION.md를 확인합니다.
- PC 관제는 루프백 전용입니다. 테스트 CA·서버 개인키, 로컬 .env, 촬영·녹음 데이터는 공유 소스와 따로 보관합니다.
- 테스트 CA를 사용한 기기에서는 시험이 끝난 뒤 해당 신뢰와 프로파일을 제거합니다.
- 현재 검증 범위는 TEST_STATUS.md에 있습니다. 실제 보행 안전 판정에 사용하지 않습니다.
